# 🎨 How to Use Translation & Correction Features

## Where to Find Them

After text is recognized (appears in the "Recognized Text" area), you'll see **filter chips** at the bottom of each text card:

```
┌─────────────────────────────────────────┐
│  Easy to read              98% confident │
│                                          │
│  [Original Text Box with text...]       │
│                                          │
│  [⚡ 3 spelling corrections - View]     │ ← NEW! Shows if corrections were made
│                                          │
│  [Simplified] [Translate] [Definitions]  │ ← Click "Translate" here!
│  [Key Words]                             │
└─────────────────────────────────────────┘
```

## ✨ Spelling Corrections (Automatic)

### How it works:
1. Text is automatically corrected after OCR extracts it
2. If corrections were made, you'll see a yellow banner: **"⚡ 3 spelling corrections applied"**
3. Click **"View"** to see what was corrected

### Example correction dialog:
```
╔════════════════════════════════════╗
║  🔧 Spelling Corrections           ║
╠════════════════════════════════════╣
║  ❌ photosynthasis → ✅ photosynthesis
║  ❌ responsable → ✅ responsible    ║
║  ❌ teh → ✅ the                   ║
╚════════════════════════════════════╝
```

## 🌍 Translation Feature

### Step 1: Click "Translate" chip
The chip will turn blue/selected when active.

### Step 2: Choose language
You'll see a language selector appear:
- **Français** (French)
- **العربية** (Arabic)

### Step 3: View translation
Two viewing modes available:

#### Full Text Mode (default):
```
┌─────────────────────────────────────┐
│  🌐 Translation (Français)          │
│                                     │
│  La photosynthèse est fondamental   │
│  pour la vie sur la Terre.          │
└─────────────────────────────────────┘
```

#### Word-by-Word Mode (click grid icon):
```
┌────────────────────────────────────────┐
│  Language: [Français] [العربية]  📊    │ ← Click this icon
│                                        │
│  ┌──────────┐ ┌───────────┐ ┌──────┐ │
│  │   The    │ │photosynthesis│ │ is │ │
│  │    ↓     │ │      ↓       │ │  ↓ │ │
│  │   le/la  │ │photosynthèse │ │est │ │
│  └──────────┘ └───────────┘ └──────┘ │
│                                        │
│  Green = Translated  Gray = Original  │
└────────────────────────────────────────┘
```

## 📝 Quick Test

### To see corrections in action:
1. Click **"Test OCR with Mock Image"** button (bottom of screen)
2. Wait for text to appear
3. Look for the yellow corrections banner
4. Click **"View"** to see what was corrected

### To test translation:
1. After text appears, click the **"Translate"** chip
2. Select **"Français"** or **"العربية"**
3. See instant translation (no loading!)
4. Toggle word-by-word view with the grid icon
5. Hover over green boxes to see original → translated

## 🎯 Features You'll See

### On Every Recognized Text Card:

1. **Correction Indicator** (yellow banner)
   - Shows when spelling was auto-corrected
   - Click "View" for detailed list
   - Shows original → corrected for each word

2. **Translate Chip** (filter button)
   - Click to enable/disable translation
   - When active, shows language selector
   - Instant results (no network delay)

3. **Language Selector** (when translate is active)
   - Segmented buttons for French/Arabic
   - RTL support for Arabic text
   - Remembers your selection

4. **View Mode Toggle** (grid icon)
   - Full text: shows complete translated sentence
   - Word-by-word: shows each word with its translation
   - Color coding: green=translated, gray=kept original

## 💡 Tips

- **Corrections are automatic** - no need to click anything, they happen right after OCR
- **Translation is on-demand** - only shown when you click "Translate"
- **Everything is offline** - no internet needed for corrections or translation
- **Instant feedback** - all processing happens in milliseconds
- **Educational focus** - 60+ science/educational terms in dictionaries

## 🔍 What Gets Corrected

Common mistakes that get auto-fixed:
- photosynthasis → photosynthesis
- mitochundria → mitochondria
- democrasy → democracy
- responsable → responsible
- teh → the
- recieve → receive
- And 50+ more!

## 🌐 What Gets Translated

Educational terms available in French & Arabic:
- Science: photosynthesis, mitochondria, respiration
- Social: democracy, citizens, government
- Environment: sustainable, biodiversity, ecosystem
- Common words: the, and, for, with, from
- And 35+ more per language!
